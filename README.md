Project Overview
The Cleaning & Hygiene Product Warehouse Management System is a web-based application designed to manage and track cleaning and hygiene product inventory for Ganga Maxx Marketplace. The system helps in organizing stock based on category, brand, pack size, warehouse location, batch number, and expiry date.

It improves warehouse efficiency by reducing manual tracking errors and ensuring better stock visibility and control.

Problem Statement
Ganga Maxx Marketplace manages a large number of cleaning and hygiene products across different warehouses. Currently, stock tracking is handled manually using spreadsheets, calls, and messages, which leads to delays, errors, and inefficiency.

There is no centralized system to track inventory, batch numbers, expiry dates, or stock movement properly. This results in stock mismanagement, expiry losses, and delayed order fulfillment.

Objectives
- To develop a centralized warehouse management system  
- To track cleaning product stock efficiently  
- To manage batch-wise and expiry-wise inventory  
- To reduce manual errors in stock handling  
- To improve warehouse operations and reporting
